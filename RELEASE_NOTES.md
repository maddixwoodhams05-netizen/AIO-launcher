## Downloads

- **Game Launcher Setup 1.0.0.exe**: the installer. Adds desktop and Start menu shortcuts. To update later, just run a newer installer, and your library is kept.
- **Game Launcher 1.0.0 portable.zip**: no install needed. Unzip it anywhere (even a USB stick) and run `Game Launcher.exe`. It keeps its library in a `Game Launcher data` folder next to itself.

**Requirements:** Windows 10 or 11 (64-bit). Nothing else to install. Steam is optional.

The two **Source code** links below are added by GitHub automatically. You don't need them to play.

Windows may show a "Windows protected your PC" message because the app isn't signed. Click **More info**, then **Run anyway**.

## What it does

- Finds your Steam games by itself, plus games in any folders you add
- Steam artwork for every game, including non-Steam games you rename
- Play button that shows Launching..., then Close game while it runs
- Playtime tracking with week / month / year charts
- Favourites, Last played and your own groups
- Storage page showing how much space each game uses, with uninstall
- Colour themes, including your own saved themes
- Search from anywhere with Ctrl+F
